Panduan Integrasi REST API (Developer Friendly)

Hubungkan sistem lisensi ini ke aplikasi desktop (Python, C#, C++), bot Discord/Telegram, atau web backend Anda secara langsung menggunakan HTTP POST request.

// 1. Klaim / Aktivasi Lisensi
POST /api/redeem
Content-Type: application/json

{
  "key": "KEY-XXXX-XXXX-XXXX",
  "identifier": "UserPC-01",
  "hwid": "CPU-XXXX-MAC-YYYY" // ID unik perangkat
}
// 2. Cek Status Lisensi (Verify)
POST /api/verify
Content-Type: application/json

{
  "key": "KEY-XXXX-XXXX-XXXX",
  "hwid": "CPU-XXXX-MAC-YYYY" // wajib jika HWID sudah terikat
}
Field hwid digunakan untuk binding 1 Key = 1 Perangkat. Setelah key pertama kali diaktifkan dengan HWID tertentu, device lain tidak bisa menggunakan key yang sama — kecuali admin melakukan Reset Perangkat di dashboard.
